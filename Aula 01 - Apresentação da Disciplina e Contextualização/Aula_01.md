# Aula 01 -- Apresentação da Disciplina e Contextualização

## Sumário

-   Apresentação da disciplina
-   Plano de ensino
-   Contexto da disciplina
-   Sequência de conteúdos
-   Metodologia
-   Critérios de avaliação
-   Atividades

## Contexto

-   Frameworks Front-end são essenciais para aplicações web modernas.
-   O Front-end é a camada com a qual o usuário interage diretamente.
-   Empresas buscam interfaces rápidas, organizadas e fáceis de manter.

## Conteúdos

-   Arquitetura de sites
-   UX, prototipação
-   Versionamento e deploy
-   JavaScript (Vanilla JS)
-   Frameworks: React, Vue e Angular
-   Componentização, estado, rotas e APIs

## Objetivos

Ao final da disciplina o aluno será capaz de: - Desenvolver interfaces
modernas. - Criar aplicações com frameworks Front-end. - Utilizar Git e
GitHub. - Publicar aplicações na Web.

## Metodologia

-   Aulas dialogadas
-   Discussões
-   Estudos de caso
-   Integração entre teoria e prática

## Avaliação

-   55% Avaliação docente
-   35% Projeto Integrador
-   10% Autoavaliação

## Atividades

1.  Projeto em HTML, CSS e JavaScript com GitHub e Vercel.
2.  Resumo da Aula 01 em Markdown.
3.  Relatório técnico sobre um framework Front-end.

## Conclusão

A disciplina introduz o desenvolvimento Front-end moderno, utilizando
boas práticas, frameworks e ferramentas amplamente utilizadas pelo
mercado.
